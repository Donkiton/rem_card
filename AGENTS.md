# Правила работы в проекте

## GitHub и рабочие изменения

- Все коммиты в GitHub — на русском языке.
- Не отправлять проект в GitHub без явного указания пользователя.
- Отправки в GitHub — через PR, если пользователь не указал иной способ.
- Обычные обратимые шаги в рамках задачи выполнять самостоятельно,
  учитывая уже выданное разрешение. Не запрашивать повторное согласование той же работы.
- Сохранять пользовательские изменения. Если запрошены только анализ или план,
  соблюдать этот режим; локальная работа сама по себе не разрешает публикацию.
- Выбирать обычные детали реализации самостоятельно. Вопрос нужен, когда
  недостающая информация существенно меняет результат, объём, стоимость
  или сохранность изменений и её нельзя надёжно установить из проекта.
- Готовность определять по требованиям и наблюдаемым проверкам; исправлять
  конкретные дефекты, не продолжать полировку без причины.
- Не переключать основную модель и уровень рассуждений без явного выбора пользователя.
- Когда Codex Dynamic Workflows включён, применять его к сложным многоэтапным
  задачам с полезным разделением работы или независимой проверкой. Простые
  задачи выполнять без оркестрации; учитывать отказ пользователя от сабагентов.

## Установщик Windows — читать перед работой

Перед сборкой, изменением или публикацией установщика прочитать
[docs/windows_installer.md](docs/windows_installer.md).

- Канонические исходники: `installer/windows/`. Основные команды и требования
  также приведены в [installer/windows/README.md](installer/windows/README.md).
- Это собственный WPF/.NET Framework 4.8 установщик, который упаковывает
  уже принятый full ZIP. Сборка приложения и сборка установщика — отдельные шаги.
- Использовать проверенный пакет с manifest, inventory и известным SHA-256.
  Не собирать дистрибутив из установленной рабочей папки или пользовательских БД.
- Проверять установщик в изолированном QA-каталоге по инструкции.
  Наличие EXE само по себе не подтверждает готовность.
- Не искать исходники по чатам и временным worktree: `tmp/` содержит только
  исторические отчёты и артефакты; рабочий источник теперь `installer/windows/`.

### Отложенное требование: русский и английский

Следующий новый выпуск установщика после 5.1.14 и последующие выпуски должны
иметь переключатель **русского и английского**, только этих двух языков.
Перед следующей сборкой реализовать и проверить это требование по разделу
«Два языка в следующем установщике» в `docs/windows_installer.md`.

В 5.1.14 переключатель ещё не реализован. Текущий установщик и опубликованный
релиз **не пересобирать и не заменять ради этого требования**: пользователь
поручил сейчас только зафиксировать будущую работу.
