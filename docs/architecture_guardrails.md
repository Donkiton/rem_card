# Архитектурные автозапреты

Автопроверка:

```powershell
python scripts\architecture_safety_check.py
```

Проверка падает, если возвращаются опасные паттерны:

- `sqlite3.connect` в UI;
- write/DDL SQL из UI;
- `DataService.run_write` из UI;
- доступ UI к private service fields;
- обход SQLite Backup API для живой БД;
- изменение network SQLite profile.

Зафиксированные инварианты network profile:

- `journal_mode = DELETE`;
- `synchronous = EXTRA`;
- `mmap_size = 0`.

Исключения допустимы только в инфраструктурных модулях, где они уже оформлены как единый безопасный путь: `sqlite_shared.py`, startup recovery и updater.

## Ограничения после рефакторинга rework

`scripts/rework_guardrails.py` подключён к этой же проверке и группе `quality`.
Он читает исходники как текст/AST, не импортируя приложение или настройки БД.

Запрещены восстановление файлов и импорты удалённых модулей:

- `services/remcard_service.py` — использовать `services/remcard_facade.py`;
- `data/dao/remcard_dao.py` — импортировать конкретный DAO;
- `ui/styles/dialog_styles.py` — действующие стили находятся в `shared_styles.py`.

Импорты проверяются в `app`, `data`, `services`, `ui`, включая относительные
импорты и псевдонимы. Упоминания в комментариях/строках не считаются импортом.
Синтаксическая ошибка или невозможность прочитать исходник проваливает проверку.
Динамически построенные пути импорта не анализируются; это статическое
ограничение обычных Python-импортов, а не доказательство всех зависимостей.

Для разобранных входных модулей установлены явные пределы физических строк,
включая пустые строки и комментарии:

| Модуль | После декомпозиции | Максимум |
|---|---:|---:|
| `ui/doctor_view/doctor_remcard_widget.py` | 301 | 450 |
| `ui/doctor_view/orders_widget.py` | 158 | 250 |
| `ui/operblock_view/operblock_main_widget.py` | 862 | 1100 |
| `services/operblock_service.py` | 73 | 150 |

Это запас для сборки компонентов и жизненного цикла, а не цель заполнить
файлы до лимита. Новая реализация относится к функциональным модулям.
Лимиты не ограничивают всю сложность системы и не заменяют существующий
Radon-контроль. Пропавший входной файл также считается ошибкой; перенос пути
требует согласованного обновления ограничения и проверки потребителей.
