# Проверки качества кода

Полный порядок локальных и GitHub-проверок: [testing.md](testing.md).

Быстрый локальный gate:

```powershell
python scripts\code_quality_checks.py
```

Он проверяет:

- `flake8 --select=F401,F402,F541,F811,F821,F841`: неиспользуемые и
  конфликтующие импорты, лишние `f`-строки, неопределенные имена и случайно
  оставленные локальные переменные запрещены полностью. Осознанно отложенные
  переменные должны иметь локальный `noqa` с объяснением.
- BOM scan: UTF-8 BOM в файлах репозитория запрещен полностью.
- `radon cc --min F`: новые блоки с оценкой сложности `F`, рост сложности
  существующих блоков и устаревшие записи baseline запрещены.

Текущие `F`-блоки и их максимальная сложность занесены в baseline внутри
`scripts/code_quality_checks.py`.
Это временный список: существующие сложные методы рефакторятся отдельными задачами, а новые `F` появляться не должны.

На текущем этапе не требуется снижать всю сложность до `D` или `C`, чтобы не создавать шум в большом существующем коде.
