# Фоны рабочего пространства

СТАНДАРТ ФОНА РЕМКАРТЫ
Создай два отдельных согласованных изображения одной композиции: light.png и dark.png.
Размер каждого: 3840 × 2160 пикселей (16:9). PNG или JPEG, sRGB, RGB без прозрачности,
без анимации; до 10 МиБ на файл, желательно до 5 МиБ. Не увеличивай маленькую картинку
вместо создания детализированного оригинала. Светлый вариант — спокойный светлый фон;
тёмный — приглушённый тёмный фон, без ярких пятен. Средняя яркость (0–255):
светлый не ниже 145, тёмный не выше 110. Это фон медицинской программы:
поверх него располагаются таблицы и панели с прозрачностью 40%. Избегай мелкого текста,
рамок, водяных знаков, контрастных узоров и значимых деталей по краям. При изменении
пропорций окна края обрезаются симметрично; изображение не деформируется.
Оба файла обязательны: тема программы всегда выбирает соответствующий вариант.

## Публикация и хранение
В Центре управления → Фон приложения выберите два файла и нажмите «Проверить и опубликовать комплект».
Обычный комплект становится основным. Для праздничного задайте даты, включая год;
периоды не должны пересекаться. После окончания периода возвращается основной фон.

Общее хранилище: `<папка базы>/settings/backgrounds/collections/`.
Каждая публикация — отдельная папка `YYYY-MM-DD_<id>` с `light.png/jpg` и `dark.png/jpg`.
`catalog.json` хранит названия, периоды и контрольные суммы; меняется только после записи двух файлов.
SQLite базы пациентов и настроек не используются. Поэтому ни изображения, ни каталог
не попадают в резервные копии базы настроек. Для полной сохранности каталог можно копировать отдельно.
Локальный кэш: `%LOCALAPPDATA%/RemCard/media_cache/<идентификатор базы>/workspace_v2/`.

Запуск использует локальные файлы, затем в отдельном потоке проверяет общую папку.
Без сети сохраняется прежний каталог. Удаление файлов на сервере не удаляет локальный кэш:
в настройках отображается «Только локально». Новый компьютер без такой копии использует «Фон».
«Убрать из каталога» прекращает назначение комплекта после синхронизации, но не удаляет файлы.
Встроенный «Фон» доступен всегда. Старые фоны предыдущего механизма не удаляются и
не включаются в новый каталог автоматически: в них нет обязательной пары тем.
Встроенная исходная пара пока сохранена в прежнем качестве 1672 × 941; это единственное
исключение из правил импорта. Генератор не выдал запрошенное нативное 4K-разрешение,
поэтому искусственное увеличение не выдаётся за улучшение детализации.

Новый комплект включается только целиком. При неудачной загрузке используется предыдущая
пригодная пара (кроме уже завершившегося праздничного периода), иначе встроенный «Фон».
Не редактируйте опубликованные файлы: для замены создавайте новую публикацию.
При аварийно прерванной публикации и отсутствии работающего издателя можно удалить
`collections/.publication.lock`. Незавершённая папка не появится в каталоге.
