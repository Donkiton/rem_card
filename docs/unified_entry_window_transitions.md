# Плавные переходы единого окна

Переход к готовой роли и возврат к выбору ролей изменяют геометрию одного окна за 240 мс с InOutCubic. Во время изменения размера содержимое скрыто за снимком и не проходит дорогостоящую перерисовку на каждом кадре. В конце целевая страница получает окончательный размер, затем снимок исчезает за 80 мс; он хранится только в памяти на время перехода. Внешняя зависимость не добавлена.

Сохраняются отдельные обычные прямоугольники и признаки разворота для приветствия и ролей. Старые настройки геометрии читаются через скрытый QWidget без изменения видимого окна. Координаты ограничиваются доступной областью подключённого монитора. Разворот использует существующий в RemCard механизм `_is_custom_maximized`, поэтому не происходит второго системного скачка после анимации.

При входе состояние busy снимается после завершения перехода. Возврат запускается параллельно освобождению ресурсов; анимация не подтверждает сохранения и не освобождает блокировки базы. Принудительный выход может отменить текущую анимацию, не сохраняя промежуточный размер роли.

Просмотрены источники:

- [MusicBox: configMainFeatures.py](https://github.com/HuberTRoy/MusicBox/blob/master/MusicPlayer/features/configMainFeatures.py): обычный showMaximized/showNormal в обработчике заголовка.
- [pyqt-frameless-window: windowEffect.py](https://github.com/yjg30737/pyqt-frameless-window/blob/main/pyqt_frameless_window/windows/src/windowEffect.py): системные эффекты Windows через DWM и оконные стили.
- [Qt QPropertyAnimation](https://doc.qt.io/qt-6/qpropertyanimation.html): интерполяция свойств, длительность и группы анимаций. Использован этот механизм, собственная реализация без переноса кода внешних проектов.

Проверки: 26 тестов и 5 subtests; промежуточные прямоугольники, точный возврат к сохранённому размеру, область разворота и обычный размер для восстановления. В настоящих Windows Qt-окнах проверены четыре роли и настройки, переключение темы, отсутствие смещения кнопок медсестры и барьер сохранений при выходе. Лог: `tmp/unified-entry-baseline/animation-smoke/run.log`.

EXE не пересобирались по указанию пользователя. Оценка плавности установленной сборки остаётся до следующей разрешённой сборки.
