# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней версии RemCard из ветки `main3.15`.

## Как сообщить об уязвимости

Используйте приватную форму **Report a vulnerability** на вкладке **Security** репозитория.
Не публикуйте описание уязвимости в открытом Issue, Discussion или Pull Request до выпуска исправления.

В отчёте укажите:

- затронутую версию;
- условия и минимальные шаги воспроизведения;
- возможное влияние;
- безопасный пример без настоящих данных пациентов, сотрудников и внутренней инфраструктуры.

Не прикладывайте рабочие базы данных, журналы, резервные копии, пароли, токены, внутренние сетевые адреса или другие закрытые данные.
